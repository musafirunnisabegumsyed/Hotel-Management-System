# 🏨 Hotel Management System

A simple and interactive **Hotel Management System website** developed using **HTML, CSS, and JavaScript**. The project provides a clean interface for exploring hotel information, viewing menus, and making booking-related interactions.

## 🌐 Live Demo

**[View the Live Website](https://musafirunnisabegumsyed.github.io/Hotel-Management-System/)**

## ✨ Features

* 🏨 Hotel information
* 📖 About the hotel
* 🍽️ Hotel menu
* 🛏️ Booking interface
* 📱 User-friendly web interface
* ⚡ JavaScript-based interactions
* 🎨 Custom CSS styling
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** – Website structure and pages
* **CSS3** – Styling and page layouts
* **JavaScript** – Interactive functionality
* **GitHub Pages** – Website deployment

## 📂 Project Structure

```text
Hotel-Management-System/
│
├── index.html       # Home page
```

## 📄 Pages

### 🏠 Home

`index.html`

The main landing page of the hotel website.

### ℹ️ About

`about.html`

Provides information about the hotel.

### 🛎️ Booking

`book.html`

Provides the interface for hotel booking-related functionality.

### 🍽️ Menu

`menu.html`

Displays the hotel's food/menu information.

## 🚀 How to Run Locally

Clone the repository:


git clone https://github.com/musafirunnisabegumsyed/Hotel-Management-System.git


Navigate to the project directory:


cd Hotel-Management-System


Then open:

```text
index.html
```

in any modern web browser.
